16タイプの性格診断

ココロタイプ

質問に直感で答えるだけで、あなたの性格タイプがわかります。
結果は男性・女性のイラストで表示。恋愛スタイルや相性のよい異性のタイプも紹介します。

✨このアプリでできること

  • 📝

    2つの診断モード

    しっかり診断（48問・約5分）と、かんたん診断（24問・約2分）から選べます。

  • 👫

    男女のイラストで結果を表示

    結果に表示するイラストを男性・女性から選べます。結果画面での切り替えもできます。

  • 💘

    恋愛の傾向と、相性のよい異性のタイプをイラスト付きで紹介します。

  • 📚

    16タイプ図鑑・相性チェック

    すべてのタイプの解説を読んだり、2つのタイプの相性を調べたりできます。

  • 📶

    オフラインで使える

    一度開けば、電波のない場所や機内モードでも使えます。

  • 🔒

    登録不要・データは端末だけ

    回答や結果はスマホの中だけに保存され、外部には送信されません。

📲スマートフォンへの入れ方

ホーム画面に追加すると、アプリのようにすぐ起動でき、オフラインでも使えます。

アプリの中のブラウザで開いています。このままではホーム画面に追加できません。

外部のブラウザで開く

画面右上（または右下）のメニューから「ブラウザで開く」を選び、iPhoneなら Safari、Androidなら Chrome で開き直してください。

  1. Safari でこのページを開きます。
  2. アドレスバーの横にある … をタップし、「共有」をタップします。 画面の下（iPadでは画面の上）に共有ボタン が表示されている場合は、そのボタンをタップします。
  3. メニューを下にスクロールして、「ホーム画面に追加」をタップします。
  4. 「Webアプリとして開く」がオンになっていることを確認し、右上の「追加」をタップします。 「Webアプリとして開く」が表示されない場合は、そのまま「追加」をタップします。
  5. ホーム画面の「ココロタイプ」アイコンから起動します。 追加したあとの最初の1回は、インターネットにつながった状態で起動してください。2回目からはオフラインでも使えます。
iPhone・iPadでのご注意
  • ホーム画面のアプリと Safari では、保存されるデータ（診断履歴など）が別々になります。
  • iPhone・iPad の Chrome などでも、共有ボタンから「ホーム画面に追加」ができます（iOS・iPadOS 16.4以降）。

  1. Chrome でこのページを開きます。
  2. 上に「アプリをインストール」ボタンが出ている場合は、それをタップします。 出ていない場合は、画面右上の ︙ メニューから「ホーム画面に追加」（または「アプリをインストール」）をタップします。
  3. 「インストール」をタップします。
  4. ホーム画面またはアプリ一覧の「ココロタイプ」アイコンから起動します。 一度開いたあとは、オフラインでも使えます。

💬よくある質問

無料で使えますか？

はい。無料で、会員登録も必要ありません。

オフラインでも使えますか？

はい。一度ページを開くと（ホーム画面に追加した場合は一度起動すると）、必要なデータがスマートフォンに保存され、電波のない場所でも使えます。

診断結果はどこに保存されますか？

お使いの端末（ブラウザ）の中だけに保存されます。外部への送信は一切ありません。アプリ内の「このアプリについて」からいつでも削除できます。なお、ホーム画面に追加せずブラウザで使っている場合、長いあいだ開かないとブラウザの仕組みで保存データが消えることがあります。ホーム画面に追加して使うと消えにくくなります。

アプリの更新はどうなりますか？

インターネットにつながっているときに新しいバージョンが見つかると、画面下にお知らせが表示されます。「更新する」をタップすると最新版に切り替わります。

アプリを削除するには？

ホーム画面のアイコンを長押しして削除できます。端末に保存されていた診断履歴も一緒に削除されます。

前回と結果が違うのはなぜ？

そのときの気分や状況によって回答が変わることがあります。どちらとも言えない指標がある場合は特に変わりやすいので、履歴で変化を見比べてみてください。
